# Delivery

This repository is delivered as documentation only. There is no build, no
toolchain, and no executable code: the whole delivery is this file.

## What is included

| Path | Purpose |
| --- | --- |
| `DELIVERY.md` | This document: what was delivered, how to check it, and what was deliberately left out. |

## How to verify

1. Confirm `DELIVERY.md` exists at the root of the repository and renders as
   ordinary Markdown.
2. Confirm no other path was added, modified, or removed. The delivery is
   additive and touches exactly one file.

There are no tests to run and no commands to execute.

## Scope

Delivered: a written record of the delivery.

Not delivered, and not to be inferred from this file: source code, build
configuration, dependencies, generated output, licences, or release
artifacts. If a later change needs any of those, it is a separate plan with
its own paths.

## Maintenance

Update this file in the same change that alters the delivery. If the path table
above no longer matches the repository, this document is wrong and should be
treated as a bug.
